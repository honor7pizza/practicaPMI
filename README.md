# Сервис заметок с категориями (REST API)

Мини-проект по производственной практике. Реализует CRUD API для управления заметками с поддержкой реляционной базы данных SQLite, фильтрацией и пагинацией.

## Архитектура проекта
* `app.py` — Главный файл сервера (Flask, роутинг, эндпоинты CRUD).
* `database.py` — Инициализация таблиц базы данных SQLite (`notes`, `categories`), поддержка связей FOREIGN KEY.
* `test_app.py` — Автоматические юнит-тесты для проверки эндпоинтов API.
* `Dockerfile` — Инструкция для контейнеризации приложения.

## Как запустить локально:
1. Установите необходимые библиотеки:
   pip install Flask flask-cors
2. Запустите веб-сервер:
   python app.py

Сервер начнет работу локально по адресу: `http://127.0.0.1:5000`

## Запуск автоматических тестов (Unit-тестирование)
Для проверки корректности ответов сервера и эндпоинтов выполните команду:
python -m unittest test_app.py

## Примеры API-запросов (curl / Postman)

1. Получить список всех доступных категорий (GET):
curl -X GET http://127.0.0.1:5000/api/categories

2. Создать новую заметку с привязкой к категории (POST):
curl -X POST http://127.0.0 -H "Content-Type: application/json" -d "{\"title\":\"Учеба СВФУ\",\"content\":\"Оформить отчет по практике\",\"category_id\":1}"

3. Получить заметки с фильтрацией по категории и постраничной пагинацией (GET):
curl -X GET "http://127.0.0?category_id=1&page=1&limit=2"
